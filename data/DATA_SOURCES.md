# Green500 data sources

Green500 starts with the latest available source version for each company and keeps the source date, reporting period, acquisition time, and content hash separate. Historical backfill is deferred. Missing or ambiguous values remain missing; the pipeline does not replace them with estimates.

## What the current implementation provides

The initial implementation provides the current constituent company list, current SEC Company Facts financial observations, and current SBTi status and target rows for companies that can be matched conservatively. It also provides the common collector and evidence pipeline for official company reports after a report URL has been confirmed. Report coverage is therefore company-specific; the existence of the collector does not mean that all 500 companies already have environmental values.

`Initial` below means that the adapter exists. `Conditional` means that the source can be added when the named access, identity, or parsing requirement is met. `Optional` means that it is outside the initial dataset and has no current source-specific adapter. Planned sources produce no observations until their adapter is implemented and run.

## Acquisition routes

- **Fixed Scrapy adapter:** a stable public URL or documented identifier-based endpoint with deterministic parsing, request limits, and source-version checks. This route fits the constituent table, SEC JSON, and public workbook downloads.
- **Agent-discovered report entry:** an agent finds an official company report, directory, or feed URL when issuer sites have no stable cross-company pattern. The saved URL then enters the same bounded collector and evidence pipeline. Discovery does not establish that a document is current or complete.
- **Permissioned import:** the operator supplies authorized credentials or a licensed file. Green500 records its provider and usage boundary. The application does not create accounts or bypass access controls.

## Emissions units

Green500 normalizes absolute greenhouse gas emissions to `tCO2e`, meaning metric tonnes of carbon dioxide equivalent. It also retains the source's original unit text. The abbreviation `mtCO2e` is accepted as metric tonnes only when the source explicitly defines it that way. Scientific notation commonly uses `MtCO2e` for megatonnes, or millions of tonnes, so capitalization alone is not enough to determine the scale. An undefined or ambiguous abbreviation remains unnormalized and requires review.

## Standards and assessments

Standards such as the GHG Protocol, SEC taxonomy, and relevant reporting frameworks define concepts and comparison rules. They do not supply a company observation by themselves. Original reports and filings supply reported facts; filing repositories distribute them; SBTi and WBA add external assessment; market providers supply observations or estimates; NGFS supplies scenarios. Green500 preserves these source classes so the interface does not imply equal authority or comparability.
