# S&P Global Sustainable1 score access

The public result page identifies a company by S&P's `cid` query parameter and displays the provider company name, industry, separate S&P Global CSA and ESG scores, whether the score is under review, a last-updated date, and whether the company participated in the CSA survey. The company-specific participation notice is parsed before the generic legend, which describes both possible participation classes. The page does not display an assessment year, separate environmental, social, and governance dimension scores, percentile, or issuer country. Missing fields stay null rather than being inferred from the current year or the last-updated date.

`company_coverage.json` records one outcome for each current Green500 company. A provider CID is included only after an exact public source establishes the company identity. Companies whose lookup has not run are `not_checked`; this does not claim that S&P has no match. Known CIDs whose current page could not be fetched are `access_blocked`; this does not claim that S&P has no score. A `matched` row contains values parsed from a fresh origin capture whose actual page URL and provider company name both matched the reviewed mapping. Unknown scores remain null.

Direct requests from the Green500 host receive an Akamai access denial. Four registered UK browser routes completed the public-page collection with disjoint company batches and atomic per-company checkpoints. The page's current autocomplete flow uses its public search-token servlet and `/api/apps/s1/query/s1-scores`; the short-lived token stays in browser memory and is redacted from saved evidence. Every accepted mapping has one unique exact normalized issuer-name match, and every displayed score also passes the result-page CID and provider-name checks. S&P's separately documented XpressAPI score and company-ID services require bearer authentication and subscriptions.

The public result page's legal section restricts storing, redistributing, and using score content to create derivative indices or investment strategies. Green500 records these use conditions with the source, identifies every value as an official S&P Global Sustainable1 score, and keeps this display separate from Green500 report coverage and index construction. A premium-only page, unsuccessful identity match, or ambiguous successor remains null; none is presented as a zero score.
